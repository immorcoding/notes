# 必须遵守的规则
1. 修改文件之前必须先询问。
2. 用户未提出要求时，尽量不修改已经写好的文件内容，除非明确要求修改
3. 任何时候语言简明扼要易理解

## Agent skills

### Issue tracker

Use GitHub Issues in `immorcoding/notes` for learning specs, substantial tasks, and questions worth tracking. See `docs/agents/issue-tracker.md`.

### Learning labels

Use `backlog`, `active`, and `waiting` as defined in `docs/agents/triage-labels.md`. Ticket dependencies are separate. Matt's engineering `/triage` workflow is not configured for this learning repository.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Learning collaboration

Choose AI assistance per task. Distinguish agent-produced artifacts from the learner's demonstrated understanding. Existing notes are not rewritten without the user's request. Background proposals and candidate experiments are not approved tasks.
