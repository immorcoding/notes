The skill map

Lesson 1 · ~10 minutes · Goal: route any situation to the right skill, including the six new ones.

Recall first

Before reading, write down the main flow from memory: which skills, in which order, take an idea to shipped code? Guessing is fine. Effortful recall is what makes it stick.

Check against the answer

/grill-with-docs → (optional /prototype detour) → /to-spec → /to-tickets → /implement or /implement-spec (both drive /tdd and finish with /code-review) → /pr → /retro.

The shape of the set

Matt's router, ask-matt, organises every skill as one main flow, three on-ramps that feed into it, and a set of standalone tools.[1]

  1. /grill-with-docs: sharpen the idea. In a repo, always prefer it over /grill-me; it leaves a GLOSSARY.md and ADRs behind.
  2. Can't settle a question on paper? /handoff → /prototype → /handoff back.
  3. Multi-session? /to-spec → /to-tickets, then build. Keep steps 1–3 in one context window.
  4. Build with /implement (one ticket, /clear between) or /implement-spec new (the whole spec in parallel).
  5. /pr new shapes the PR body; /retro new improves the environment for next time.

On-ramps: /triage (issues you didn't write), /diagnosing-bugs (something's broken), /wayfinder (too big and foggy for one session).

What's new for a regular user

/implement-spec vs /implement

/implement builds one ticket, and you drive. /implement-spec reads all tickets as a task graph, runs implementer subagents in their own worktrees across the ready frontier, and merges into one integration branch, with a single /code-review at the end.[2]

/retro

Fixes the environment, not the code. A mechanical mistake becomes a deterministic check (linter, pre-commit hook, CI). A judgement call becomes a coding standard. Run it before you /clear.[3]

/pr, /wizard: model-invoked

You rarely type these. The agent reaches for /pr whenever it writes a PR, and for /wizard when it hits a step only a human can do (secrets, dashboards).[4]

/to-questionnaire, /wait-what

/to-questionnaire is the inverse of /grill-me: the answer is in someone else's head, so it grills you about who it's for and what you need back.[5] /wait-what repairs one confusing message; a glossary built early prevents the next one.[6]

Check your repos. Skills now read GLOSSARY.md, not CONTEXT.md. resolving-merge-conflicts is gone, and writing-great-skills is now writing-for-agents.[7]
