/wait-what

  • Re-pitch with context, Simplified Technical English, GLOSSARY.md words.
  • Good result = shorter and clearer, adds the missing premise. Bad = just blunter.
  • Prevention: /grill-with-docs builds the glossary upfront.

/wizard

  • Scope → map clicks → author stages in template.sh → verify statically. You run it.
  • Helpers: stage say step open_url ask ask_secret write_env set_secret set_var confirm pause.
  • Value destinations:
.env onlylocal dev needs it, CI doesn't
GitHub secretCI needs it, sensitive
GitHub variableCI needs it, public
bothlocal + CI
nowherepure action (jumper, switch, plan upgrade)
  • confirm before anything irreversible. One screen per stage.
  • No back button: Ctrl-C, re-run, saved values return as defaults.
  • Ephemeral unless the next person needs it.

/to-questionnaire

  • Asks only: who is it for? what do you need back? Never the subject.
  • Doc: purpose · from/to · context · how to answer · themed questions (most-important-first, one idea each, answer stub) · anything else?
  • One recipient per run. Flat, not branching. Doesn't send.
  • Run in the same conversation as a stalled grilling; feed answers back to /grill-with-docs or /to-spec.
