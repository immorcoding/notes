Skill map

mattpocock-skills v1.3.1, one line per skill. new = added to the plugin in 1.2–1.3.

U = user-invoked (you type it). M = model-invoked (the agent may reach for it on its own). A user-invoked skill can call model-invoked ones, never another user-invoked one.[readme]

Main flow: idea → ship

SkillReach for it when…
/grill-with-docsUSharpening an idea in a repo. Leaves GLOSSARY.md + ADRs.
/handoffUMoving work to a new directory, harness or colleague (e.g. a prototype detour).
/prototypeMA question needs a runnable answer. Kept on a prototype/<name> branch.
/to-specUMulti-session build: turn the thread into a spec.
/to-ticketsUSplit a spec into tracer-bullet tickets with blocking edges.
/implementUBuild one ticket (or small work right here). /clear between tickets.
/implement-spec newUBuild a whole spec at once: parallel subagents over the ticket graph, one integration branch.
/tddMRed-green-refactor, one vertical slice at a time.
/code-reviewMReview diff since a fixed point on two axes: Standards + Spec.
/pr newMWriting a PR body: smallest visual, before/after evidence, one-way/two-way door.
/retro newUAfter a build: fix the agent's environment (checks, standards, pointers), not the code.
