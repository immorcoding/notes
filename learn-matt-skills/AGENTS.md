# learn-matt-skills

Teaching workspace for `/mattpocock-skills:teach`.

At the start of a session here, before anything else, give the user a short status (3–5 lines):
1. Where they left off: read `MISSION.md` and the newest files in `learning-records/`.
2. What to read: the files in `reference/` (cheat sheets), and the latest lesson in `lessons/` if a lesson is unfinished.

Don't restate the status from memory: always derive it from these files, so it stays current.
