# 1. 不同指令集架构 cpu 寄存器定义 #
关于不同指令集架构 cpu 寄存器，每个系列的通用寄存器数量、定义不一定相同，具体如下表(几个例子)：

| cpu 指令集架构 | 通用寄存器 | 其它特殊寄存器 |
|:---:|:---:|:---:|
| ARM Cortex-M (ARM v6/7/8-M) | 16 个 (R0-R15, 其中R13 (SP), R14 (LR), R15 (PC)) | xPSR, CONTROL, PRIMASK, BASEPRI, FAULTMASK |
| ARM AArch32 | 16 个 (R0-R15, 其中R13 (SP), R14 (LR), R15 (PC)) | CPSR、SPSR 等 |
| ARM AArch64 (ARM v8/v9-A) | 31 个 (X0-X30, 其中X30 (LR)) | SP、PC、PSTATE 及系统寄存器 |
| RISC-V RV32/RV64 | 32 个 (X0-X31, 其中X0 (zero), X1 (ra), X2 (sp)) | PC、CSR (mstatus、mtvec、mepc 等) |
| x86-64 | 16 个 GPR | RIP、RFLAGS、控制寄存器等 |
| MIPS32/64 | 32 个 GPR | PC、HI、LO、系统控制寄存器等 |

# 2. 关于 Cortex-M 的系列的详细寄存器定义 #
## 通用寄存器

- **R0 ~ R12**  
  真正意义上的通用寄存器 (GPR, General Purpose Register)。

## 栈指针寄存器

- **R13（SP, Stack Pointer）**  
  栈指针寄存器。Cortex-M 架构中实际提供 **MSP（Main Stack Pointer）** 和 **PSP（Process Stack Pointer）** 两个 **banked Stack Pointer**，而 **R13/SP 表示当前正在使用的栈指针**，并不是额外独立于 MSP、PSP 之外的第三个栈指针寄存器。
  - **MSP（Main Stack Pointer）**：主栈指针，保存主栈当前的栈顶地址。复位后默认使用 MSP，**Handler Mode（中断/异常处理模式）固定使用 MSP**。
  - **PSP（Process Stack Pointer）**：进程栈指针，保存进程栈当前的栈顶地址，通常用于 RTOS 中各任务的任务栈。
  在 **Thread Mode** 下，当前 SP 使用 MSP 还是 PSP 由 `CONTROL.SPSEL` 位决定：
  - `CONTROL.SPSEL = 0`：**SP = MSP**
  - `CONTROL.SPSEL = 1`：**SP = PSP**
  在 **Handler Mode** 下，不受 `CONTROL.SPSEL` 控制，***SP 始终使用 MSP***。
  因此可以简单理解为：
  ```text
  Thread Mode：
  CONTROL.SPSEL = 0 → R13/SP 使用 MSP
  CONTROL.SPSEL = 1 → R13/SP 使用 PSP

  Handler Mode：
  R13/SP 固定使用 MSP
  ```
  ***MSP 和 PSP 内部保存的都是栈顶地址；R13/SP 表示当前活动的那个 Stack Pointer。***

## 链接寄存器

- **R14 (LR, Link Register)**  
  链接寄存器，用于保存函数调用返回地址。

## 程序计数器

- **R15 (PC, Program Counter)**  
  程序计数器，用于保存下一条指令的地址。

## 程序状态寄存器

- **xPSR (Program Status Register)**  
  程序状态寄存器，用于保存当前程序的状态信息。

  **xPSR** 可进一步划分为：
  - **APSR (Application Program Status Register)**：应用程序状态寄存器
  - **IPSR (Interrupt Program Status Register)**：中断程序状态寄存器
  - **EPSR (Execution Program Status Register)**：执行程序状态寄存器

## 中断屏蔽寄存器

- **PRIMASK**  
  用于屏蔽可配置优先级的中断。

- **BASEPRI**  
  用于设置中断优先级阈值。
  这个优先级阈值与 FreeRTOS 的优先级配置有关，FreeRTOS 会根据任务的优先级来设置 BASEPRI，从而实现对中断的屏蔽和允许，以及临界区的管理。
  > 部分 Cortex-M 系列支持。例如：Cortex-M3、Cortex-M4、Cortex-M7。 而 Cortex-M0/M0+等 不支持 BASEPRI。

- **FAULTMASK**  
  用于屏蔽除 NMI 之外的异常。  
  > 部分 Cortex-M 系列支持。例如：Cortex-M3、Cortex-M4、Cortex-M7。 而 Cortex-M0/M0+等 不支持 FAULTMASK。
